# Security policy

## Reporting a vulnerability

**Please don't open a public GitHub issue for a security problem.**

Report it through Infisical's vulnerability disclosure policy at <https://infisical.com/vulnerability-disclosure>. Include what you found, where, how to reproduce it, and what an attacker could achieve.

The scope of the program, its safe harbour and its coordinated disclosure terms are set out in that policy.

## Supported versions

Security fixes ship in the latest release of `@infisical/cipher`. Upgrade to it to pick them up.
